# DWFE G2 TP2

This project is a simple website starter built with React, JavaScript, and CSS.

## Getting started

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Build for production:
   npm run build

## Project structure

- `src/App.jsx` - main page component
- `src/styles.css` - styling
- `src/main.jsx` - React entry point
- `index.html` - HTML template

## Notes

This structure is intentionally simple to help you begin your TP2 project and extend it with more pages and features.
